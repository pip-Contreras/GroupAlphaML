# GroupAlphaML
This program preprocesses and analyzes heart disease datasets as well
as implements classification algorithms to predict heart disease risk.

## Requirements
In order to properly run this program, ensure you have Python 3.10 or higher
and install all dependencies using 'pip install -r requirements.txt'.

## How to Run This Program
This program is prepared to using the terminal in VS Code

### Steps:
1. Install VS Code with Python and Jupyter extensions.
2. Open a terminal with the directory containing this program.
3. Run the program with the command `python main.py` (or the equivalent)

Original datasets used for this project:
heart_2022_with_nans.csv:
https://www.kaggle.com/datasets/kamilpytlak/personal-key-indicators-of-heart-disease

heart_disease_health_indicators_BRFSS2015.csv:
https://www.kaggle.com/datasets/alexteboul/heart-disease-health-indicators-dataset
